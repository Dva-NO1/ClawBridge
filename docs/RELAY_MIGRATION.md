# 更换中继服务器与真机连通验收说明

ClawBridge 采用零硬编码设计，更换 VPS 中继服务器时无需修改任何代码或重新编译 APK。

---

## 1. 更换中继服务器步骤

### 步骤一：在新 VPS 一键部署中继
```bash
cd relay/deploy
sudo bash deploy.sh --domain relay.new-domain.com --email you@new-domain.com
curl https://relay.new-domain.com/healthz
```

### 步骤二：桌面桥切换中继地址
- **图形界面**：打开桌面托盘 `ClawBridge` 控制台 → 在「中继服务器地址」填入 `wss://relay.new-domain.com` → 点击 **「保存并应用」**；
- **配置文件**：编辑 `%APPDATA%\clawbridge\config.json` 中的 `relayUrl` 并重启服务。
- 桌面桥检测到中继地址变化后会自动清空旧 token，并向新中继申请新的 6 位配对码。

### 步骤三：手机 App 切换中继地址
- 打开 App **「设置 → 中继服务器」** → 填入 `wss://relay.new-domain.com` → 点击 **「保存中继设置并重连」**；
- App 自动断开旧中继、连接新中继并跳转首页，输入电脑端新生成的 6 位配对码即可完成迁移。

---

## 2. 真机连通验收清单

1. **首次配对**：输入 6 位配对码，首页状态切换为「已直连 · 桌面在线」并显示毫秒延迟。
2. **5G 独立连通**：关闭手机 Wi-Fi，仅保留 5G/4G 移动数据（无 VPN），1–3 秒内自动恢复在线。
3. **电脑休眠唤醒自恢复**：渲染本休眠后手机显示「桌面离线」；唤醒电脑登录桌面后 1 分钟内（通常 2–10 秒）自动恢复在线。
4. **核心功能回归**：查看双端剩余额度、搜索并打开会话、发送中英文消息与图片/文件、验证低风险直接批准与高风险 PIN 拦截。
